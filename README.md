## 🚀 Fitur Interaktif & Efek Animasi Modern ("Bisa Bergerak")
1. **Dynamic Typing Text Effect:** Headline di hero section mengetik secara dinamis secara bergantian:
   - *"Perancang Arsitektur Sistem & Basis Data"*
   - *"Pengembang Laravel & PWA Offline-First"*
   - *"Spesialis Optimasi Alur & Proses Bisnis"*

2. **Animated Number Counters:** Angka metrik (IPK 3.80, 100% Standar UML, -70% Waktu Antrean) menghitung naik secara dinamis saat di-scroll.
3. **Interactive 3D Mouse Tilt Effect:** Kartu profil dan kartu proyek bergerak miring secara halus mengikuti pergerakan kursor mouse pengguna.
4. **Scroll Progress Bar:** Garis indikator gradien rose-gold di bagian paling atas layar yang memanjang saat pengguna men-scroll halaman.
5. **Floating Lighting Orbs & Micro-Badges:** Orbs bercahaya halus mengambang perlahan di latar belakang dan badge melayang di sekitar avatar.
6. **Filter Proyek Interaktif:** Filter kategori (*Semua*, *Analisis Sistem & PWA*, *Inovasi Proses*, *Kepenulisan Teknis*) dengan transisi halus.
7. **Sistem Modal Deep-Dive Arsitektur:** Jendela pop-up berisi diagram skema ERD, alur kerja PWA, formula asesmen Kurikulum Merdeka, dan diagram 5-Whys.
8. **Salin Email Cepat + Notifikasi Toast:** Tombol salin email satu klik dengan banner feedback meluncur dari sudut bawah.
9. **Pratinjau CV / Resume:** Tampilan CV lengkap standar ATS dengan tombol *Cetak / Simpan PDF*.

## 🌐 Cara Mengakses & Menjadikannya Online di Internet (Bisa Diakses Siapa Saja)

Website ini murni dibuat dengan **HTML5, CSS, dan JavaScript**, sehingga sangat ringan, cepat, dan **100% GRATIS** untuk di-online-kan di internet:

### Cara 1: Buka Langsung di Komputer (Offline / Tanpa Server)
1. Buka folder `D:\portofolio` di File Explorer Windows Anda.
2. Klik 2x (double-click) pada file `index.html`.
3. Website akan langsung terbuka di browser Anda (Google Chrome / Edge) dengan seluruh animasi aktif!

### Cara 2: Online Gratis dalam 1 Menit via Netlify Drop (Paling Mudah)
1. Buka browser dan kunjungi: **[app.netlify.com/drop](https://app.netlify.com/drop)**
2. Tarik (drag and drop) seluruh folder `d:\portofolio` ke area kotak di website tersebut.
3. Dalam hitungan detik, Anda akan langsung mendapatkan link website aktif resmi seperti:  
   `https://sugiati-portfolio.netlify.app` yang bisa langsung dibagikan ke recruiter atau klien!

### Cara 3: Online via GitHub Pages
1. Buat repository baru di akun GitHub Anda (misal: `portofolio`).
2. Upload semua file dari folder `d:\portofolio` ke repository tersebut.
3. Buka menu **Settings > Pages**, pilih branch `main`, lalu simpan.
4. Website Anda akan aktif di: `https://username.github.io/portofolio`.
